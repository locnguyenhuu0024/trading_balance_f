6. **Execution:** execute task only when dependencies PASS, worktree clean, allowlist safe, variant lock passes, task ready with RED/GREEN and buildability criteria. Exactly one Codex writer per checkout in v0.5.
7. **Audit:** independent Claude review of code, relevant callers, tests, RED→GREEN, Task Buildability Gate, final integration and repository build. Executor output is REVIEW_REQUIRED only.
8. **Variant requirements:** Ponytail minimal complete changes everywhere. Company QA handoff; personal RTK/Headroom; frontend F0–F3 and design/visual audits, as applicable.
9. **Telemetry:** only coordinator writes canonical OptCodex event JSONL and weekly metrics. CCB task_ledger.py is a separate metadata-only ledger: planner records task, executor records start/finish, auditor records outcome; task IDs and attempts are separate. Do not invent actual token usage, model identity, timings or checks.
10. **Safety:** preserve protected-config no-read/no-write rules, user-specific Git approvals, controlled external services and environment failure short-circuit. Do not silently patch executor failure as coordinator.
